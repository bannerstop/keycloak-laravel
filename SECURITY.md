# Security policy

## Reporting a vulnerability

Please do not open a public issue for security problems. Report them privately,
either by e-mail to [dev@bannerstop.com](mailto:dev@bannerstop.com) or through
GitHub: open the **Security** tab of this repository and choose **Report a
vulnerability**. We will get back to you and keep you posted until a fix is
released.

Token verification, login state and the other security-critical parts live in
the core package [bannerstop/keycloak](https://github.com/bannerstop/keycloak);
its [security policy](https://github.com/bannerstop/keycloak/blob/main/SECURITY.md)
describes what is checked and what is left to the application.
